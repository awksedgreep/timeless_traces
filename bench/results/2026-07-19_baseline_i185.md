# Baseline Before Perf Port (i185)

**Date:** 2026-07-19
**Machine:** Intel Core Ultra 9 185H ("i185"), Linux, 22 schedulers
**Version:** timeless_traces 1.3.16 (branch perf/read-path-and-backpressure,
pre-fix), local prod BEAM, fresh data dir.
**Workload:** `bench/container_http_workload.exs` — 16 writers x ~500-span
OTLP JSON POSTs (traces of 3-7 spans), auto-ramp, 10 Jaeger query workers
(service search, service+operation, trace-by-id, services list).
Client shares the machine (same caveat as the timeless_logs runs).

## Result: the same disease timeless_logs had

| Interval | Spans/s | Write p99 | Query p50 | Q/s |
|----------|--------:|----------:|----------:|----:|
| 1.0s | 8.0K | 23.6ms | 96.5ms | 49.4 |
| 500ms | 15.9K | 13.1ms | 514ms | 17.3 |
| 250ms | 31.6K | 8.5ms | 1.25s | 8.3 |
| 125ms | 62.3K | 12.4ms | 1.86s | 4.2 |
| 62ms | 121.6K | 14.0ms | 5.96s | 1.3 |
| 31ms | 227.5K | 20.9ms | — | 0.6 |
| 15ms | 419.9K | 23.9ms | — | 0.2 |
| 7ms | **466.8K** | 33.2ms | — | 0.9 |

- **The 467K spans/s "peak" is an accept rate, not durable**: the client
  sent ~20.3M spans; disk held 10.8M at bench end — ~9.5M spans buffered
  in memory, server RSS 6.7GB and climbing (no drain-coupled
  backpressure; same failure mode as logs' 32GB).
- **Queries collapse immediately**: p50 96ms at only 8K spans/s, seconds
  by 30K, effectively zero completions past 120K
  (`count_total: true` default + the `overlapping_blocks?` full-collection
  escalation defeat early-exit; every search decompresses every matching
  block).
- 10,333 blocks / 4.85GB on disk at bench end.

## Fix order (see docs/2026-07-18_perf_audit_plan.md)

Port from timeless_logs 1.5.0, validating each against this harness:
read path (count_total off on HTTP + per-term counts + honest
early-exit) → drain-coupled backpressure gauge → bounded parallel
compactor + adaptive level → query concurrency cap → hot tail →
memoized batch term extraction.

timeless_logs went from this exact profile to: durable wall 388K
entries/s, query p50 3-17ms across the whole ramp, RSS bounded ~1GB.
